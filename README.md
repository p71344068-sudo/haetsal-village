# 햇살 마을 — 아이폰 홈 화면 앱

합성 퍼즐로 에너지를 모아 3D 섬 마을을 짓는 게임이에요.
이 폴더 전체가 하나의 앱이에요. 설치는 한 번만 인터넷 주소에 올리면 되고, 그 다음부터는 오프라인에서도 실행돼요.

## 1. 인터넷 주소에 올리기 (둘 중 하나)

**A. Netlify Drop (가장 쉬움, 컴퓨터 필요)**
1. 컴퓨터 브라우저에서 https://app.netlify.com/drop 접속
2. 이 `haetsal-app` 폴더를 통째로 끌어다 놓기
3. 생성된 `https://….netlify.app` 주소를 복사 (무료 계정으로 가입하면 주소가 계속 유지돼요)

**B. GitHub Pages**
1. GitHub에 새 저장소를 만들고 이 폴더의 파일을 모두 올리기
2. 저장소 Settings → Pages → Branch를 `main` / `(root)`로 지정
3. `https://아이디.github.io/저장소이름/` 주소가 생겨요

## 2. 아이폰에 설치하기
1. 아이폰 **Safari**로 위 주소 열기 (Chrome 앱 말고 Safari)
2. 아래쪽 **공유 버튼(⬆︎)** → **홈 화면에 추가** → 추가
3. 홈 화면의 🏡 **햇살 마을** 아이콘으로 실행하면 주소창 없이 전체 화면으로 열려요

## 알아두면 좋은 점
- 첫 실행 때 파일을 기기에 저장하므로, 그 다음부터는 비행기 모드에서도 플레이할 수 있어요.
- 진행 상황은 아이폰 안에 저장돼요. 홈 화면 앱을 삭제하면 진행 상황도 함께 지워져요.
- 게임을 수정해 다시 올릴 때는 `sw.js`의 `VERSION` 값을 바꿔야(예: `haetsal-v2`) 이미 설치된 앱이 새 버전을 받아요.

## 파일 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 게임 전체 (화면, 합성 보드, 3D 마을) |
| `vendor/three.min.js` | 3D 엔진 Three.js r128 (MIT 라이선스, `three-LICENSE.txt`) |
| `sw.js` | 오프라인 실행을 위한 캐시 |
| `manifest.webmanifest` | 앱 이름·아이콘·전체 화면 설정 |
| `icons/` | 홈 화면 아이콘 |
